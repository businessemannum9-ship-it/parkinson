# Parkinson's Clinical Education Website

موقع عربي ثابت للتثقيف حول مرض باركنسون، مبني باستخدام HTML وCSS وJavaScript دون إطار عمل أو اعتماديات خارجية للتشغيل.

## التشغيل محليًا

1. افتح `index.html` مباشرة في متصفح حديث، أو شغّل خادم ملفات ثابتًا من مجلد المشروع.
2. عند توفر Python، يمكن تشغيل الأمر `python -m http.server 8000` ثم فتح `http://localhost:8000`.
3. لا يلزم تثبيت حزم أو إعداد قاعدة بيانات.

## الملفات

- `index.html` — أقسام الموقع والمحتوى التعليمي.
- `style.css` — التصميم المتجاوب وتنسيقات الطباعة.
- `app.js` — البحث، التصفية، الحالة التعليمية، قالب الرعاية والتنقل.

## الميزات الحالية

- تنقل داخلي متجاوب بين الأقسام، مع قائمة هاتف قابلة للفتح.
- بحث في موضوعات الدليل، وتصفية مرجع الأدوية ومكتبة المصادر.
- محتوى عن التقييم والتشخيص التفريقي والأدوية والمضاعفات والرعاية متعددة التخصصات.
- نموذج حالة تعليمية متدرج مع أسئلة وتغذية راجعة.
- قالب خطة رعاية ومواد تثقيفية قابلة للطباعة.
- لوحة متابعة شكلية؛ جميع معلومات العينة توضيحية وخيالية ولا تمثل قياسات أو سجلات مرضى.

## حدود الاستخدام والتطوير

الموقع واجهة أمامية ثابتة. لا توجد مصادقة أو قاعدة بيانات أو حفظ أو إرسال للمعلومات، ولا تُعد لوحة المتابعة نظامًا سريريًا آمنًا. لا تدخل معلومات صحية تعريفية. قبل استخدام أي بيانات حقيقية، يلزم تطوير خادم آمن مع مصادقة وتفويض وتخزين مناسب وتحقق خادمي وامتثال للأنظمة المحلية، إضافة إلى مراجعة طبية للمحتوى والترجمات.

المعلومات تعليمية وليست تشخيصًا أو وصفة أو بديلًا عن الحكم الطبي. رابط NICE NG71 وتاريخ المراجعة المعروض مأخوذان من صفحة الإرشاد الأصلية؛ تحقّق دائمًا من المصدر نفسه لأي تحديث لاحق.
